# Pinned exactly, not left open-ended: qdrant-client's local/embedded
# storage format is tied to the specific client version. An open range
# (">=1.9") let this app's own machine and Railway's build independently
# resolve to different actual versions at different times, and a newer
# client trying to open data written by an older one caused a Pydantic
# schema mismatch on collection creation. Pinning guarantees Railway
# installs the exact version this qdrant_data/ was actually built with.
qdrant-client==1.19.0
# Pinned rather than left open-ended: newer sentence-transformers releases
# pull in a transformers version that requires torch>=2.4, but PyTorch
# stopped building wheels for Intel Macs after 2.2.2 - that combination
# is simply uninstallable there. These versions are confirmed compatible
# with torch>=1.11, so this works on Intel Macs, Apple Silicon, and Linux.
# torch itself is deliberately NOT pinned here - pip will pick whatever
# version your platform actually has wheels for (2.2.2 on Intel Mac,
# newer elsewhere), and both pins below are compatible with any of those.
